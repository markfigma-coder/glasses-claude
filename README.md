# Клод в очках

Голосовой ассистент Claude для умных очков **Ray-Ban Meta**: говоришь в очки — Claude отвечает голосом в их динамики. Разговоры сохраняются по темам, темы раскладываются по папкам, можно писать и текстом.

*Voice assistant for Ray-Ban Meta glasses powered by Claude. iOS app built on the Meta Wearables Device Access Toolkit and the Claude API. UI is in Russian.*

## Возможности

- Голосовой разговор через микрофоны и динамики очков (распознавание русской речи на iPhone)
- «Живая» сфера на главном экране: тап — начать разговор, во время ответа — прервать
- Режим «отвечать на любую фразу» или только на фразы, начинающиеся с «Клод, …»
- История: каждая беседа сохраняется отдельной темой, Claude сам даёт ей короткое название
- Папки, поиск по темам и сообщениям, переименование, перенос, удаление
- Текстовый ввод на главном экране и внутри темы
- Выбор модели: Claude Sonnet 5.5 или Haiku 5.5
- Камера очков (кадр к вопросу «что я вижу?») — в коде есть, но пока выключена (`GlassesManager.cameraEnabled`)

## Что нужно

- **Mac с Xcode 26.4 или новее** (SDK Meta собран на Swift 6.3)
- **iPhone с iOS 17.2+**
- **Очки Ray-Ban Meta** (Gen 1 или Gen 2), подключённые к приложению Meta AI, с актуальной прошивкой
- **Свой ключ Claude API** — [platform.claude.com](https://platform.claude.com) → API Keys. Запросы оплачиваются с твоего аккаунта: вопрос стоит порядка цента
- Apple ID (бесплатного хватит, но тогда приложение нужно переустанавливать раз в 7 дней)

> Claude API доступен не во всех странах. Если запросы возвращают 403 — твой регион не поддерживается.

## Установка

### 1. Режим разработчика в Meta AI
Meta AI → Settings → App Info → **5 раз тапни по номеру версии** → включи Developer Mode. Если появится кнопка **Install** — нажми её, она ставит на очки модуль для сторонних приложений. Установка идёт по прямому Wi-Fi между очками и iPhone: если обрывается, временно выключи VPN.

### 2. Сгенерировать проект
```bash
brew install xcodegen
git clone https://github.com/<твой-аккаунт>/glasses-claude.git
cd glasses-claude
```
Открой `project.yml` и замени `com.marksimonov.glassesclaude` на свой уникальный идентификатор, например `com.<твоё-имя>.glassesclaude`. Потом:
```bash
xcodegen
open GlassesClaude.xcodeproj
```
Xcode сам скачает SDK Meta (`meta-wearables-dat-ios` 1.0.1).

### 3. Подпись и запуск
1. Таргет **GlassesClaude** → **Signing & Capabilities** → **Team**: свой Apple ID.
2. Подключи iPhone кабелем, выбери его вверху и нажми **▶︎**.
3. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл. Затем Настройки → Основные → **VPN и управление устройством** → доверься своему сертификату.

### 4. Первый запуск
1. Шестерёнка → вставь ключ Claude API.
2. **«Подключить»** → подтверди в Meta AI → вернёшься обратно.
3. Надень очки → тап по сфере. Разреши микрофон и распознавание речи.
4. Говори — отвечу после паузы.

Meta AI не закрывай свайпом: связь с очками идёт через него, его можно только свернуть.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `GlassesManager.swift` | Регистрация в Meta AI, сессия с очками, диагностика подключения, камера (выключена) |
| `VoiceEngine.swift` | Микрофон очков по Bluetooth HFP или микрофон iPhone, распознавание речи, озвучка ответов |
| `ClaudeClient.swift` | Запросы к Claude Messages API, автоназвание темы |
| `Assistant.swift` | Логика разговора: фраза → Claude → ответ голосом, статусы |
| `Library.swift` | Темы, папки, сообщения; хранятся в JSON на iPhone |
| `ContentView.swift`, `LibraryView.swift`, `SettingsView.swift`, `Theme.swift` | Интерфейс |

Ключ API хранится только в Keychain на устройстве и нигде в коде не лежит.

## Ограничения

- Звук с микрофонов очков идёт в 8 кГц (Bluetooth HFP), поэтому в шуме распознавание может ошибаться. Можно переключиться на микрофон iPhone в настройках — тогда и голос ответа в очках станет чище.
- Приложения на Meta Wearables SDK пока нельзя публиковать в App Store — только своя сборка через Xcode или тестировщики через release channels Meta.
- Видео с камеры очков в текущей версии отключено.
